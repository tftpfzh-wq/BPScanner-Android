# BP Scanner — نسخه آزمایشی 0.1.0

سورس برنامه اندروید BP Scanner.

## ساخت APK
با هر push به شاخه main، GitHub Actions باید APK آزمایشی را بسازد. خروجی در بخش Actions و Artifact با نام BPScanner-debug-apk قرار می‌گیرد.

## هشدار پزشکی
این برنامه فشار خون را اندازه‌گیری نمی‌کند. تخمین ضربان قلب در این نسخه آزمایشی و اعتبارسنجی‌نشده است و برای تصمیم پزشکی مناسب نیست. برای سنجش فشار خون از دستگاه کاف‌دار معتبر استفاده کنید.
